# 🧮 Math Practice Quiz Generator

A random math practice quiz generator with 100 questions each session, covering addition, subtraction, multiplication, and division.

## ✨ Features

- **🎲 Random Generation** - Automatically generates 100 different questions each time the page opens
- **📊 Three Question Types** - Comprehensive coverage of addition/subtraction, multiplication, and division
- **📈 Real-time Statistics** - Shows score, accuracy rate, and progress
- **✍️ Instant Feedback** - Displays correct/incorrect feedback immediately upon submission
- **📝 Answer Records** - Sidebar displays answer status for all questions
- **🏆 Final Grading** - Shows final score and performance rating
- **⌨️ Quick Input** - Supports Enter key for quick submission
- **🔄 Restart Anytime** - Support restarting a new round of practice

## 📋 Question Ranges

### 1️⃣ Addition/Subtraction (within 1000)
- Addition: Sum of two numbers does not exceed 1000
- Subtraction: Minuend is greater than subtrahend
- Avoids adding or subtracting 0
- Examples: 456 + 234 = 690, 789 - 123 = 666

### 2️⃣ Multiplication (3-digit × single-digit)
- Multiplicand: 1-999
- Multiplier: 2-9
- Examples: 234 × 5 = 1170, 999 × 9 = 8991

### 3️⃣ Division (3-digit ÷ single-digit, divisible)
- Dividend: 1-999
- Divisor: 2-9
- Guaranteed to be evenly divisible with no remainder
- Avoids dividing by 1 and quotient 1
- Examples: 168 ÷ 8 = 21, 900 ÷ 9 = 100

## 🎮 User Guide

### Getting Started

1. **Open Page**
   - 100 random questions are automatically generated when the page loads
   - Start from question 1 by default

2. **Answer Flow**
   - Questions are displayed in a large card in the center
   - Enter your answer in the input field
   - Click "Submit" button or press Enter key
   - Instant feedback showing correct/incorrect

3. **Navigation**
   - **Previous** - View the previous question
   - **Next** - Jump to the next question
   - **Record Sidebar** - Click any question number to jump directly to that question

### Statistics Panel

At the top statistics bar, you can see:
- **Question** - Current progress (e.g., 1/100)
- **Score** - Number of correct answers (e.g., 15/100)
- **Accuracy** - Answer accuracy percentage (e.g., 85%)
- **Restart** - Start a new round immediately

### Record Sidebar

- **Unanswered** - Displayed in gray
- **✓ Correct** - Displayed in green with checkmark
- **✗ Incorrect** - Displayed in red with X mark
- **Current** - Current question highlighted

### Completion Screen

After answering all 100 questions:
- Shows final score and accuracy rate
- Displays grade based on accuracy:
  - 🌟 **90%+** - Excellent
  - 👍 **80-89%** - Good
  - 😊 **70-79%** - Passed
  - 😕 **60-69%** - Needs Improvement
  - 💪 **Below 60%** - Keep Going

## 💡 Learning Tips

1. **Progress Gradually** - Complete questions one by one, don't skip
2. **Think Carefully** - Think independently about each question, don't guess
3. **Review Answers** - If you get it wrong, carefully check the correct answer
4. **Practice Multiple Times** - New questions appear each time you open, practice more
5. **Analyze Mistakes** - Note down wrong question types and focus on strengthening them

## 🔧 Technical Details

- **Frontend Implementation** - No server required, runs completely locally
- **Random Algorithm** - Questions vary each time they are generated
- **Smart Division** - Division questions are generated by multiplication to ensure 100% divisibility
- **Responsive Design** - Automatically adapts to various screen sizes

## 🎯 FAQ

**Q: Can I save my progress?**  
A: Currently not supported. Refresh will generate new questions. Recommend completing all questions in one session.

**Q: Are the questions too easy/difficult?**  
A: Question difficulty automatically adjusts based on grade level. You can modify parameters in script.js to customize.

**Q: Does it support negative numbers?**  
A: Current subtraction generates results, but doesn't create negative number problems (minuend ≥ subtrahend).

**Q: Can I customize questions?**  
A: Yes, you can edit the generation functions in script.js to customize question types and ranges.
